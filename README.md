# 微信接手器 · Morrow Reply

**把微信咨询、岗位推荐、小程序入口和招聘群运营放进一个工作台。**

微信接手器是一款运行在 Windows 电脑上的微信接待与招聘运营软件。连接本机已登录的微信后，客服可以在同一界面处理求职咨询、查看回复草稿、推荐现有岗位、发送原生小程序首页卡片，并管理群发与固定进群入口。

适合地方招聘平台、招聘客服和需要持续接待求职者的团队。接待规则由使用者配置，支持先审阅再发送，也支持按设置自动接待，客服可以随时接管会话。

## 能做什么

| 功能 | 实际用途 |
| --- | --- |
| 微信私聊接待 | 合并连续发来的碎片消息，保留会话上下文，生成草稿或自动回复；支持暂停、转人工和恢复接待。 |
| AI 招聘接待 | 结合企业资料和现有岗位库理解地区、薪资、工种、班次等要求，承接追问、岗位编号选择与联系方式咨询。 |
| 关键词话术 | 按配置的关键词发送预设回复，不调用模型接口，适合固定咨询与标准话术。 |
| 新好友欢迎 | 在新好友已通过验证、被识别为接待对象后，按设置主动欢迎，并可附带小程序首页入口。 |
| 原生小程序卡片 | 使用当前微信账号已分享到“文件传输助手”的原卡片，核验来源与目标后转发；首页卡片需匹配已配置的小程序资料。 |
| 招聘群运营 | 保存固定、动态或混合发布名单，预览目标后即时或定时群发文字、已有小程序卡片；任务使用创建时确认的群名单。 |
| 固定进群入口 | 配对后自动筛选最新可用招聘群，读取微信原生群二维码并更新同一个网址，减少运营人员反复换链接的工作。 |
| 图片与语音处理 | 可使用支持视觉输入的模型识别求职图片；语音消息可准备文字引导并触发 Windows 通知，提醒客服处理。 |
| 多账号管理 | 最多管理 4 个微信账号，各号的连接、接待设置、联系人范围、会话记录、卡片来源与群名单按账号隔离。 |
| 企业资料与岗位库 | 配置品牌、地区、办公地址、小程序资料；导入岗位 JSON，或通过只读招聘接口同步岗位。 |
| 运行记录与诊断 | 查看文字、卡片与拉群的分项结果，导出或上传诊断包，定位连接、搜索、发送和更新异常。 |

同一安装中的企业资料、岗位库和模型接口共用；各微信账号的接待与投递记录分别管理。

## 一条典型的接待流程

求职者发来咨询 → 识别求职条件 → 查询已有岗位 → 生成回复 → 客服审阅或自动发送 → 引导查看小程序、联系岗位或进入最新招聘群。

如果资料不足、生成失败或需要人工处理，对应记录会留在工作台，便于客服继续跟进。发送结果不明的消息不会自动重发。

## 安装与开始使用

支持 **Windows 10 1809 及以上 / Windows 11，Intel 或 AMD x64**。安装包自带 Node.js、Python 与桥接依赖，无需用户另外安装这些运行环境。

1. 下载并安装标准安装包，从桌面或开始菜单打开“微信接手器”。界面会在系统默认浏览器中打开。
2. 在电脑微信登录业务账号，在工作台的账号管理中扫描、添加并连接对应账号。
3. 在“接待设置”选择关键词话术或 AI 招聘接待，配置本账号的联系人范围、欢迎语与发送方式。
4. 使用 AI 接待时，配置模型地址、模型名称与密钥；使用岗位推荐时，填写企业资料并导入或同步实际岗位。
5. 使用首页卡片时，先用同一个微信账号把原生小程序首页卡片分享到“文件传输助手”，再配置对应的小程序资料。
6. 先用审阅模式核对话术与接待对象，再按需要开启自动发送。应用内对话试跑只生成模拟结果，不向真实联系人发送。

首次安装需要自行配置企业与业务数据。关闭网页后后台服务仍会运行；停止程序请使用开始菜单中的“停止微信接手器”。

## 固定进群入口怎么用

固定入口需先由维护者开通，并分配与业务微信账号绑定的配对码。当前群设置位于 **AI 招聘接待的接待设置** 中。

1. 在拥有业务群的微信账号上连接接手器，找到“固定进群入口”。
2. 输入一次性配对码，开启“自动更新最新群二维码”，首次点击“立即获取并更新二维码”。
3. 取码成功后，把固定网址用于客户进群引导；之后按群名筛选条件、编号与人数上限自动选择最新可用群。

运行时每分钟检查群目录，同一个群每 6 小时重新读取二维码；换群时先撤下旧码，取得新码后再展示。取码失败按间隔重试，超过 12 小时未更新的二维码停止展示。

新群须先加入绑定的微信账号，并出现在该账号的群目录中。读取需要微信已登录、接手器已连接、桌面解锁，以及 Windows 简体中文 OCR；取码期间会短暂切到目标群。扫码入群遵循微信自身的群容量、权限与入群限制。

## 更新软件

已有 0.8.4 及以上标准安装版：**更多工具 → 软件更新 → 检查更新 → 一键更新**。

更新优先从主源下载，失败时切换 GitHub 备用源；客户端验证更新清单签名、安装包大小与 SHA256。每次启动会在后台检查更新，发现新版显示入口提示，由使用者选择下载安装。

也可以用新版安装包覆盖安装到原目录，沿用已有业务数据、规则和配对。更新前保存未完成的设置与草稿；更早的解压版迁移需要单独处理。

## 使用条件与当前范围

- 微信操作依赖本机已登录、可操作的兼容电脑版微信和解锁的桌面。普通接待流程中，搜索、发送或取码可能短暂切换微信窗口。
- 好友申请的通过、账号登录与验证码由使用者在微信完成；软件接待已成为好友的客户。
- 普通群聊和公众号消息不进入私聊自动接待；群发任务在独立功能中配置。
- 当前语音功能是文字引导与人工提醒；图片识别需要所选模型支持视觉输入。
- 原生群邀请提供手动或自动调用与结果记录，其可用性取决于微信界面和群权限。发送或邀请结果不明时保留待核对记录。
- 工作台以本机使用为主。四个真实账号同时长期运行、不同电脑及微信版本下的持续稳定性仍需分别验证。

## 数据保存与联网说明

接待记录、规则、岗位库与接口配置主要保存在本机。标准安装版的数据目录为 `%LOCALAPPDATA%\WeChatReceiver\data`；API 密钥在本机加密保存，主密钥也在数据目录内。备份前先停止程序，完整保留数据目录和 `master.key`。

以下功能会联网并传输相应资料：

- **AI 接待与图片识别**：把完成本轮任务所需的消息上下文、岗位资料或图片发送到你配置的模型服务。接口费用和数据处理规则由该服务决定。
- **云端诊断**：自动上传默认开启，可在“故障诊断”中关闭。诊断包可包含设备与账号标识、联系人信息、最近消息和回复摘要、错误与运行日志；软件会尝试遮蔽常见 API 密钥，也支持仅导出本地诊断包。
- **固定进群入口**：开启后，将所选群的名称和原生二维码上传到已配对的入口服务，供客户通过公开网址查看。
- **岗位同步与软件更新**：访问你配置的招聘接口或软件发布源。

请妥善保管本机数据目录。公开发布仓库只托管安装包、签名清单和说明；分享软件时应使用标准安装包。
