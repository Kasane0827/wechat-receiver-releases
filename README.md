## 本版更新

- 修复 Windows 更新完成后停在“正在重启”的收尾问题；旧版助手兼容启动与本机升级已验证。
- 联系人支持跨页“全选全部联系人”，搜索不会限制全选范围，保存设置后生效。
- 设置简化为“我怎么用？ / 图片 / 语音”，直接配置 AI 或脚本，详细规则收进开发者选项。
- 修复图片识别开启 JSON 输出时可能返回 HTTP 400 的请求格式问题。图片需要支持图片输入的多模态模型，不确定时转人工。
- 语音文字提示为“现在不方便收到语音，请发文字”，Windows 通知与红点提醒人工处理。
- 改善已验证账号的窗口恢复与发送等待反馈；结果不确定的消息不会自动重发。

## 安装和更新

支持 Windows 10 1809+ / Windows 11、Intel/AMD x64。安装包自带运行环境。

已有安装版可直接覆盖安装到原目录，**不要先卸载**。0.8.4 及以上安装版也可使用“更多 → 软件更新 → 检查更新 → 一键更新”。

一键全选入口：**设置 → 开发者选项 → 接待联系人 → 全选全部联系人 → 保存设置**。手动名单最多 10000 位，超出会提示，不会静默截断。

微信发送仍需要已登录客户端、可操作微信窗口和未锁定桌面。当前版本尚未实现无窗口静默发送，长期无人值守稳定性未验证。
